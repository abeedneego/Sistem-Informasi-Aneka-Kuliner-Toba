# Sistem Informasi Aneka Kuliner Toba
Sistem Informasi Aneka Kuliner Toba (2023) merupakan proyek pertama saya menggunakan tools Figma. Pada tahap pembelajaran ini, UI Interface dibuat tanpa prototipe yang terstruktur dan beberapa elemen masih menggunakan aset dari screenshot. Proyek ini menjadi langkah awal saya dalam mempelajari UI Interface dan penggunaan tools Figma.
